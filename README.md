# Ahmed Abdallah — Marketing Strategy Portfolio

A web portfolio presenting my work across marketing strategy, content systems, market research, paid media, and creative production.

**Live portfolio:** [ahmed-strategy-portfolio.vercel.app](https://ahmed-strategy-portfolio.vercel.app)

## What is inside

- Ten web-native marketing case studies across nine industries
- Strategy decks and content calendars rebuilt for quick online reading
- Paid ads evidence with campaign results and next-action commentary
- AI-generated legal video showcase created with Higgsfield
- Three live digital products across education, logistics, and healthcare
- Cloud9 organic-growth evidence, production trackers, captured Reels, and a bilingual tour funnel
- Original campaign visuals, reels, research findings, and planning frameworks
- Responsive layouts, accessible navigation, restrained motion, and optimized media

## Technology

React, Vite, React Router, Framer Motion, and custom CSS. The production site is hosted on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
```

## Updating the portfolio

- Project case-study content: `src/data/projects.js`
- Paid media evidence: `src/data/paidAccounts.js` and `src/data/paidCampaigns.js`
- Site-wide profile and contact content: `src/data/site.js`
- Images, videos, logos, and covers: `public/`
